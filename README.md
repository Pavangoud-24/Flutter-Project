ABSTRACT

The Job/Internship Finder is a Flutter-based mobile application designed to help students, fresh graduates, and job seekers easily discover suitable job and internship opportunities. The application provides a simple and user-friendly interface where users can browse available opportunities, search for specific roles, and filter jobs based on skills, location, experience, and job type.

Users can view detailed information about each opportunity, including company name, job description, required skills, location, and other relevant details. The application can also provide features such as saving favorite jobs, tracking applied opportunities, and managing a user profile.

The main objective of this project is to simplify the job-search process by bringing relevant opportunities into a single mobile platform. The project also demonstrates the use of Flutter and Dart for cross-platform mobile application development and can be extended in the future with authentication, cloud databases, notifications, resume uploads, and personalized job recommendations.
